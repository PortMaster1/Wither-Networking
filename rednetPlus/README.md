# Rednet Plus

## Installation:
1. Copy RednetPlusInstaller/ folder to peripheral.
2. Create and write your desired hostname into the file `/etc/hostname`, eg `rockbottom.net`
3. Run `lua require rednetPlusInstaller` on the peripheral
4. If successful, delete the `RednetPlusInstaller` folder.

Run `require rednetPlus`
